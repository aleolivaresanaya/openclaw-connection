# Herramientas de Nova

## Conexiones existentes
- Zapier MCP: acceso mediante mcporter y la configuración existente del VPS.
- Google Docs: anteriormente se probó la acción Create Document From Text.
- Google Calendar: anteriormente se probó la acción Create Detailed Event.
- Telegram: bot existente de Nova, configurado mediante emparejamiento.
- Comprueba la disponibilidad actual antes de ejecutar cada acción.
- No asumas acceso a Gmail, Drive, Tasks o GitHub solo porque aparezcan en el curso.

## Cuándo usar cada herramienta
- Google Docs: guardar diarios de aprendizaje, resúmenes y planes solicitados por Ale.
- Google Calendar: consultar o crear bloques de estudio cuando las acciones disponibles lo permitan.
- Telegram: responder a Ale en su conversación privada y confirmar resultados.
- mcporter: consultar las herramientas disponibles y ejecutar las acciones existentes de Zapier.

## Convenciones
- Idioma por defecto: español.
- Zona horaria: America/Mexico_City.
- Diario de aprendizaje: título "Diario de aprendizaje de Ale - YYYY-MM-DD".
- Plan de estudio: título "Plan de estudio de Ale - YYYY-MM-DD".
- No inventes un calendario, carpeta, destinatario o identificador.
- Usa el destino predeterminado de una acción solo si está configurado y es inequívoco; en otro caso pregunta.
- Si no existe una acción para actualizar documentos, crea un documento nuevo por entrada y explica ese comportamiento.
- No añadas invitados ni envíes correos sin confirmación.
- Verifica el resultado con la respuesta del servicio y proporciona el enlace o identificador disponible.
- Si la herramienta no permite verificar un resultado, indícalo expresamente.
- Nunca copies credenciales ni endpoints privados en estos archivos.
